<header class="header">
<p class="lead"><span style="font-family: 'times new roman', times, serif; font-size: 12pt;">SPCsim (Sneak Path Current Simulator) enables you to quickly analyze sneak path currents in passive memristor arrays, a key factor in non-volatile memories and analog in-memory and neuromorphic computing systems. Based on IMEC A14 (1.4 nm) technology, SPCsim allows you to enter a few design parameters: array size, K<sub>on</sub>, V<sub>dd</sub>, data pattern, connection strategy, and interconnect layer. The model instantly calculates the sneak path current, helping you explore different designs and optimize array performance, no complex setup required. <strong><a href="https://aineu.pages.dev/" target="_blank" rel="noopener">SPCsim V1.0</a></strong>.</span></p>
